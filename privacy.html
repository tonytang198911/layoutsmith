1. 关于 Layoutsmith

Layoutsmith（排版大师）是一款主要在本机运行的排版与设计工具。GitHub Pages 上的页面用于介绍产品，不托管用户的项目数据或 Pinterest 访问令牌。

2. 我们读取哪些 Pinterest 数据

在你主动连接 Pinterest 并授权后，应用通过 Pinterest API 读取你授权的账户、Board 和 Pin，用于在应用内展示并让你选择图片作为设计参考。应用不会读取你未授权的 Pinterest 内容。

3. 数据如何使用

  • 从 Pinterest 读取的 Board / Pin 图片只在应用内展示，并由你选择是否作为设计参考使用；
  • 我们不会出售、出租或向广告商共享你的 Pinterest 数据；
  • Pinterest 访问令牌仅保存在你本机的配置目录中，不存放在 GitHub Pages 或我们的服务器上；
  • 应用不收集分析、广告或行为追踪数据。

4. AI 功能

当你主动使用 AI 功能并发送文字、画板截图或参考图片时，这些内容会发送给你在应用中配置的 AI 服务提供商，用于生成排版建议或内容。是否发送由你决定；不发送时 AI 不会读取你的画板。

5. 本地数据与删除

项目、字体和品牌素材保存在你的浏览器本地存储（IndexedDB / localStorage）或本机应用目录中。你可以通过应用内的删除功能清理项目，或直接删除本机配置目录来移除 Pinterest 令牌和本地数据。

6. 撤销 Pinterest 授权

你可以随时在 Pinterest 的账户设置中撤销此应用的访问权限，也可以在应用中断开 Pinterest 连接。撤销后，应用将无法继续读取你的 Pinterest 内容。

7. 第三方链接

本应用可能包含指向 Pinterest、GitHub 等第三方网站的链接。这些网站的数据处理受其各自的隐私政策约束。
