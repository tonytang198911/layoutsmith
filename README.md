# 排版大师 · Layoutsmith

一个跑在浏览器里的本地排版工具，适合灯箱片、海报、菜单牌和大幅面画面。没有 Illustrator 也能把 LOGO、PS 导出的元素、文字和矢量图形拼到实物尺寸的画板上，导出 PNG / JPG / SVG，或者直接打印成 PDF 交给制作方。

所有项目只存在这台电脑的浏览器里，不上传服务器。

---

## 启动

**macOS**：双击 `启动.command`。如果系统提示「无法打开」，右键 → 打开。

**Windows**：双击 `启动.bat`（需要装 Python 3）。

**手动启动**（任意系统）：

```bash
cd layoutsmith
python3 launcher.py
```

浏览器会自动打开 `http://127.0.0.1:8787/`。关掉终端窗口就停止。

> 为什么要起一个小服务？浏览器直接打开 `index.html` 时不能可靠地保存项目，字体、图片和导出也会受限制。这个脚本只监听本机 127.0.0.1；只有你主动使用 AI 绘制 / 看画板时，浏览器才会把描述（和开启视觉时的截图）通过本机转发给对应的 AI 服务。
>
> **macOS 桌面快捷方式**：`~/Desktop/排版大师.app`。双击即可打开；服务已在运行时直接开浏览器，未运行时会后台启动本机 8787，不会弹终端。日志在 `/tmp/layoutsmith-desktop.log`。快捷方式依赖当前应用文件夹路径，移动 `layoutsmith` 后需要重新生成。停止服务可在终端执行 `pkill -f launcher.py`。
>
> AI 绘制也依赖这个脚本里的本地转发（`/api/chat` 和 `/api/vision`）。用普通静态服务器打开时，其它功能正常，但 AI 对话框会提示代理不可用。

如果不想在对话框里填 Key，也可以在启动时用环境变量（只会存在本机进程里）：

```bash
DEEPSEEK_API_KEY=sk-你的key python3 launcher.py
```

## 功能

**项目**
- 首页像 CapCut 一样列出项目，带缩略图、尺寸、修改时间；可搜索、排序、重命名、复制、删除。
- 新建时可选常用尺寸（1000×2000、1200×2400、800×1800、2000×1000 横版、1500×3000 等），也可以自定义毫米尺寸和 DPI。
- 项目可以下载为 `.layoutsmith.json` 文件换电脑导入，建议重要项目定期备份。

**画布**
- 无限画布，画板按实物毫米尺寸摆放；可以放多个画板，分别导出。
- 新建画板会自动排到所有现有画板的右侧（间隔 100mm），尺寸和底色沿用当前画板，不会叠在原画板上；建完自动缩放到全部画板。
- 左侧「画板」列表底部有「新建画板 / 适应全部画板」；⇧⌘0 也能适应全部。旧的叠在一起的画板不会自动移动，选中后在右侧改 X，或删除画板后重加。
- 左侧「图层 / 画板 / 品牌」和画布之间的竖线可以左右拖动，调窄或调宽左侧栏；双击竖线恢复默认，宽度会记住。
- 右侧属性面板默认收起；点顶栏的面板图标可以手动展开。选中画布对象或左侧图层时自动展开，取消选择后自动收起；点左侧画板列表里的画板也会展开画板设置。
- 点击画板外的空白处会**取消画板选中**（顶部显示「—」，蓝色画板边框消失，右侧属性收起）；点击画板重新选中。未选中画板时 `⌘0` / 底部「适应」会适应全部画板，AI 仍会继续工作。
- 拖动**画板标签**（带 ⠿ 手柄）或画板**边框**可以移动画板，画板中心点内的对象会跟随一起移动；开启吸附时会和相邻画板/参考线对齐。右侧 X / Y 会同步，拖完按 `⌘Z` 一次撤销。
- 画板可以全部删除，不再强制保留最后一个。删掉最后一个后会进入无画板状态，画板上的对象仍留在画布上；可以新建画板或让 AI 重新生成。空画板项目重新打开也会保持 0 个画板。
- 空格拖动平移，⌘ + 滚轮缩放，⌘0 适应画板，⌘1 回到 100%。
- 顶部 / 左侧标尺；从标尺拖出参考线，拖动移动，拖回标尺或按 ⌫ 删除。
- 移动、画图形时自动吸附参考线、画板边缘和中心、其它对象的边和中心，可一键关掉。
- 预览模式（⇧P）会把画板外内容遮住，跟导出结果一致。

**插入素材**
- 图片按钮 / 直接把 PNG、JPG、WebP、SVG 拖进画布；也支持从剪贴板 ⌘V 粘贴图片。
- 图片按原始像素置入，可缩放、旋转、替换，导出时不会因为画布缩放而变糊。
- SVG 以矢量源文件方式载入（浏览器栅格化渲染）。

**文字**
- 双击进入编辑，支持字号、字重、斜体、下划线、大写、对齐、行高、字距、内容。
- 字体：常用系统字体下拉 + 直接输入任意本机字体名；「本机字体」可扫描 Chrome/Edge 里已安装的字体；也可以上传 .ttf/.otf/.woff 字体文件（会保存在浏览器里）。
- 文字可以填充纯色 / 渐变，也可以描边、加阴影 / 发光。

**矢量图形**
- 矩形（含圆角）、椭圆、正多边形 / 星形、直线、钢笔路径。
- 填充：无 / 纯色 / 线性渐变 / 径向渐变，渐变可调角度、色标颜色和位置。
- 描边：粗细、颜色或渐变、实线 / 虚线 / 点线。
- 透明度、混合模式、阴影 / 发光。
- 路径查找器：**合并（并集）**、**相减**、**交集**、**排除重叠**，保留贝塞尔曲线。
- 编组 / 解组、多选、对齐（相对选区或画板）、层级、锁定、隐藏。

**品牌库**
- 首页右上角「品牌库」、编辑器左侧「品牌」页签，或 ⌘B 打开。
- 存 Logo、图标、纹理、PS 导出的元素；支持 PNG / JPG / WebP / SVG，可以按 Logo / 图形 / 图片 / 其他归类。
- 在左侧「品牌」里点素材就会插入当前画板；也可以把素材拖到画布上。品牌色会出现在右侧填充/描边色板和品牌页签里，点一下应用到选中对象。
- 把排好的画板「存为模板」；模板可以套到当前画板，也可以在模板页直接「新建」一个同尺寸项目。保存模板会记录文字、图形和图片。
- 品牌素材、模板、品牌色和品牌字体都存在本机浏览器；项目文件不包含品牌库，换电脑需要保留原始素材文件。

**AI 绘制 / 改画板（DeepSeek + 视觉，底部面板）**
- 右上角「AI 绘制」或 ⌘K 打开编辑器底部的 AI 面板；打开项目时会自动出现。可以直接描述新画面，也可以说「把价格改成 30.000」「标题放大一点」「整体更暖」，不需要在单独的弹窗和画布之间来回导入。
- AI 可以**一次生成多个独立画板**：先给出画板清单（名称/尺寸/底色），再按顺序给每张 SVG；结果会直接建在现有画板右侧，画板名称显示在画板外，同类型相邻，最后自动适应全部。一次最多 50 个；数量多时可以分批生成。
- AI 的修改会**直接作用到画布**：改现有对象、生成新画板、批量建板都自动应用，⌘Z 一次撤销；AI 面板保持打开，可以继续下一条指令。
- AI 也能**直接移动 / 排列画板**：对象清单的 `artboards` 里有每张画板的 id、名称和绝对 x/y；让它「按一行一门店 / 每行 N 张 / 同类相邻重排」，它会返回目标坐标，客户端把画板连同画板内对象一起移动并自动适应视图，⌘Z 撤销。
- AI 也能**直接新建可编辑文字 / 行标签**：让它「给每行左侧加门店类型文字标签」，它会返回 `texts`（文字、坐标、宽度、字号、颜色），客户端创建真正的 Textbox，图层里可继续编辑；可以同时返回画板排列和文字，先移板再加字，适应视图会把这些标签也算进去。行标签在画板外，单独导出某张画板时不会带出去。
- AI 的**新建能力**覆盖：画板（带 SVG 内容或 `blank:true` 空画板）、可编辑文字、矩形、椭圆、直线、多边形、星形、路径、品牌图片/`data:` 图片；统一用 `objects` / `texts` / `artboards` 指令落到画布。AI 不能凭空生成照片；图片只能来自品牌库或已有图片。编组、布尔运算、参考线、导入外部文件仍由手动操作完成。
- AI 面板和画布在同一个编辑器里。标题旁的「让 AI 看当前画板」控制视觉分析；参考 / 链接 / @ 引用 / Pinterest 和发送在同一行，发送靠右。面板右上角是**最小化**而不是关闭：缩小到最下面一行，点最大化或顶部「AI 绘制」恢复；也可以拖面板上边缘调整高度。输入框上边框可以上下拖动调整高度，双击恢复自动高度；高度会记住。
- 对话和画布中间的**竖线**可以左右拖动，鼠标放上去会变成左右箭头；双击竖线恢复默认宽度。对话和画布宽度的调整也会记住。
- **参考附件**：点「参考」上传图片 / PDF / TXT / MD；也支持拖拽或直接粘贴图片。PDF 在本机用 PDF.js 提取文字、**每一页的毫米尺寸**（最多 50 页）和第一页预览；图片参考需要开启「看画板」才会发给视觉模型。每次最多 6 个参考。
- AI 多画板会优先按 PDF 每页尺寸 / 用户给的尺寸 / @ 画板尺寸建板；即使模型少写了画板元数据，客户端也会读取每个 SVG 自己的 width/height 作为画板尺寸，不再统一套用当前画板大小。
- **Pinterest / 链接**：点「链接」添加 Pinterest Pin 或网页；Pinterest 会尝试抓取标题、描述和封面图（受 Pinterest 限制时仍保存链接）。点「Pinterest」按钮直接打开你设置的个人主页；第一次点会问主页链接。这不是 Pinterest 登录/OAuth，只是快捷入口；AI 不会浏览整个 Pinterest。
- 参考文件里的文字、链接说明会作为资料交给 DeepSeek；参考图片和当前画板截图一起交给视觉模型。参考内容是资料，不会当成指令执行。
- **让 AI 看当前画板**：点对话框里的眼睛按钮，发送时会把当前画板截图交给视觉模型分析；同时，DeepSeek 会拿到一份精确的**对象清单**（文字、id、毫米坐标、颜色、字体、层级）。
- **@ 引用**：点输入框下方的「@ 引用」，或直接输入 `@`，可以选画板、图层、品牌元素 / 品牌模板；选中的引用会以标签显示，随指令一起交给 AI。AI 会拿到所有画板的完整对象清单（每个对象标注所在画板），因此可以跨画板改图层，也会读取 @ 的品牌套件（品牌色、字体、素材名）来配色排版。
- **AI 设置**：顶栏「AI 绘制」旁边的小齿轮打开模型 / DeepSeek Key 设置；AI 面板标题栏不再放模型和 Key。面板标题栏右侧只有最小化 / 最大化。
- 改现有画面时，DeepSeek 返回**对象级修改**（ops），应用后直接改文字 / 颜色 / 字号 / 位置 / 删除，不会重画整张，也不会把文字变成图片。可以 ⌘Z 撤销。
- 新画面仍然生成 **SVG**（可编辑矢量组）或 **HTML/CSS**（位图）；「替换上次插入」适合反复改同一张。
- 第一次用：在对话框里填 DeepSeek API Key。保存后会同时记在当前浏览器和本机配置里（应用文件夹上一级的 `.layoutsmith/deepseek.key`，权限 600），换浏览器/清站点数据都不用重填；旧版浏览器里已保存的 Key 会自动迁移。请求通过本机 8787 只转发给 AI 服务，不写日志。
- 视觉默认走 OVHcloud 的匿名免费视觉链（和 DSH 的 vision-router 默认兜底同一类服务），可能限流。也可以在 AI 对话框里点「看画板」旁边的齿轮，直接填 **服务地址 / 模型 / API Key**，保存后立即生效，不用改环境变量；视觉 Key 也只存在本机浏览器。
- 同一画板没有改动时，会复用上一次的视觉分析，减少调用；改动画板后自动重新看图。
- 也可以换成你自己的 OpenAI 兼容视觉模型（本地 Ollama / Qwen-VL / GLM-4V / OpenAI 等）：
```bash
VISION_BASE_URL=http://127.0.0.1:11434/v1 VISION_MODEL=qwen2.5vl python3 launcher.py
```
  - 云端服务再加 `VISION_API_KEY`；可设 `VISION_MODELS=a,b,c` 做降级链。默认视觉只发送当前画板截图，不发送项目文件；但图片会离开本机，敏感画面请用本地视觉模型或关闭「看画板」。
- 即使视觉服务失败/限流，对象清单仍然可用，AI 仍能精确改现有元素；视觉主要补充整体观感、OCR 和排版问题。
- DSH 的 `vision-router` 插件是给 Harness 智能体的工具，不直接向独立网页暴露接口；这里复用的是它的视觉后端思路（视觉模型看、DeepSeek 改），不是插件工具本身。

**导出**
- PNG / JPG：按 DPI 输出实际像素；大画板建议 72–150 DPI，300 DPI 适合小尺寸。
- SVG：1:1 毫米尺寸、文字仍是文字、图片内嵌，适合给印刷厂。
- PDF 打印：打开打印窗口，页面尺寸已按实物毫米设置，选择「存储为 PDF」即可得到矢量 PDF。
- 透明画板导出 PNG 会保留透明通道。

## 单位与尺寸

- 画布内部单位是**毫米**。画板、位置、字号、描边粗细、阴影都以 mm 显示。
- 字号输入框可以切 mm / pt（1pt = 0.3528mm），方便按习惯输入。
- 换算：`像素 = 毫米 ÷ 25.4 × DPI`。例如 1000×2000mm 在 150DPI 下是 5906×11811px。

## 数据与备份

- 项目存在浏览器的 IndexedDB（同域名 + 端口）。清空浏览器数据、换浏览器、换端口都会看不到项目。
- 项目卡片菜单 → **下载项目文件**，会得到一个包含画布 JSON 和图片数据的 `.layoutsmith.json`，可在另一台电脑用首页的「导入」打开。旧版的 `.lbs.json` 备份也仍然可以导入。
- 上传的字体保存在当前浏览器里，**不会**写进项目文件；换电脑后如果用到上传字体，需要重新上传/安装。
- 品牌库（素材 / 模板 / 品牌色 / 品牌字体）也是本机浏览器数据，和项目分开；项目备份不包含品牌库。
- 导出 SVG / PNG 是交付文件，不包含可编辑的图层信息。长期归档建议同时保留 `.layoutsmith.json`。
- DeepSeek API Key 保存在当前浏览器 + 本机配置文件（应用文件夹上一级的 `.layoutsmith/deepseek.key`，权限 600），不写进项目文件，也不会被静态服务读到；在界面上清除 Key 会删除这个文件。换电脑要重新填（或用环境变量）。

## 已知边界

- 没有直接编辑路径节点（钢笔画完不能再拖点）、没有图片裁切、没有 CMYK / 专色 / PDF/X。灯箱厂若要求印刷级 PDF，请用导出的 SVG 在 Illustrator 里做最后处理，或提供 300DPI PNG。
- 文字不能直接转曲，也不能参与路径查找器；需要布尔运算的文字请先在 Illustrator 里转曲，再以 SVG/PNG 放进本工具。
- SVG 里的文字引用字体名，对方电脑没有同款字体时会替换；需要固定外观请导出 PNG，或把文字在 AI 里转曲。
- 浏览器对超大位图有内存上限：单张导出限制约 8000 万像素、单边 20000px。超大画面优先用 SVG / PDF。
- AI 的视觉分析是模型观察，可能不精确；改现有元素时以对象清单 + ops 为准。默认免费视觉可能限流，重要项目建议配置自己的视觉端点。
- HTML/CSS 插入是按 2 倍左右分辨率截图，印刷请优先让 AI 输出 SVG，或把 HTML 里的设计改成 SVG。
- 使用 DeepSeek / 视觉服务会产生 API 费用；Key 请只在自己的电脑上保存。开启「看画板」时当前画板截图和参考图片会发给视觉服务；PDF 文字在本机提取。Pinterest 预览需要访问 Pinterest。
- 除 AI 绘制外，本工具只在本机运行；字体扫描依赖浏览器的 Local Font Access 权限（Chrome / Edge 支持）。

## 画板锁定

在左侧「画板」列表点某张画板右侧的锁，或选中画板后在右侧属性面板点「锁定画板」：

- 锁定后该画板不能拖动，板内图层不能选中、移动、删除或修改；
- 画板属性字段会禁用，画板列表和画布标签显示锁定状态；
- 再点一次解锁即可继续编辑；对象自身的锁定状态会保留；
- 支持 ⌘Z 撤销，锁定状态会随项目保存。

## 画板裁切

选中超出画板的元素，右侧属性面板 → **画板裁切 → 裁切到画板**，就只显示画板范围内的部分。裁切范围固定在画板上，拖动画板时会跟着画板移动；可以随时“取消裁切”。按 ⌘Z 撤销。

## Pinterest（可选）

AI 面板左下角的 Pinterest 按钮会打开 Pins / Boards 选择器：

- App ID：`1644778`（已预填）；
- Trial access 审核通过前，Pinterest 会把 App Secret 和 Redirect URIs 锁成灰色；这时点 Pinterest 页面的 **Generate Access Tokens**，把 token 填进本机设置表单的 **Access Token** 字段即可先读取 Pins / Boards（token 只存本机，过期后重新生成）。
- 审核通过后，把 `http://localhost:8787/api/pinterest/callback` 加到 **Configure → Redirect URIs**，再填 App Secret，就可以用正常的 OAuth 授权。
- 点“连接 Pinterest”完成 OAuth 后，可以按 Board 浏览、选图，把图片加入 AI 参考；
- App Secret / token 只保存在本机 `.layoutsmith/pinterest.json`（权限 600），不会进入 GitHub 仓库；
- 选图会占用 AI 参考名额（当前上限 6 个）；Pinterest 只读，不发布内容。

## 连不上 DeepSeek / 公司代理证书

如果报 `CERTIFICATE_VERIFY_FAILED` 或 `self signed certificate in certificate chain`，通常是 Python 自带的 CA 链不完整，不是 DeepSeek 挂了。启动器现在按主流 agent 的做法使用**操作系统信任链**，不关闭证书校验：

- 默认读取 macOS 的 `/etc/ssl/cert.pem`，也兼容 Linux CA 路径和 certifi / truststore；
- 可以用 `SSL_CERT_FILE=/path/to/company-ca.pem`（或 `LAYOUTSMITH_CA_BUNDLE`）显式指定公司根证书；
- `/api/health` 里的 `sslCa` 会显示当前使用的证书链来源；
- 修改环境变量后重启本地服务即可生效。
